# Aplikasi Restoran Sederhana (Java)

Tugas Praktik 1 - Pemrograman Berorientasi Objek.

## Fitur Utama:
- Manajemen Menu menggunakan **Array**.
- Sistem Pemesanan tanpa looping (Maksimal 4 item).
- Perhitungan Pajak (10%) dan Biaya Pelayanan (Rp20.000).
- Logika Diskon 10% jika pesanan > Rp100.000.
- Penawaran Beli 1 Gratis 1 Minuman jika pesanan > Rp50.000.

## Cara Menjalankan:
1. Compile file: `javac Main.java`
2. Run program: `java Main`
3. Masukkan nomor indeks menu dan jumlah pesanan saat diminta.
